# CodeAlpha Data Analytics Internship Tasks

This repository contains my completed tasks for the CodeAlpha Data Analytics internship.

| Task | Project | Folder | Standalone repository |
|---|---|---|---|
| Task 1: Web Scraping | Online Bookstore Price & Rating Analysis | [`task1-web-scraping`](task1-web-scraping) | [CodeAlpha_BookScraper](https://github.com/Sasa20267/CodeAlpha_BookScraper) |
| Task 2: Exploratory Data Analysis | Superstore Sales & Business Performance Analysis | [`task2-superstore-eda`](task2-superstore-eda) | [CodeAlpha_SuperstoreEDA](https://github.com/Sasa20267/CodeAlpha_SuperstoreEDA) |

## Task 1: Web Scraping

Scraped all 1,000 books from [Books to Scrape](https://books.toscrape.com/) across 50 listing pages and 50 category pages using requests and BeautifulSoup, then cleaned the data and analyzed prices, ratings and categories with pandas and matplotlib.

## Task 2: Exploratory Data Analysis

Analyzed 51,290 order lines from the Global Superstore dataset (2011-2014): cleaning and checks, profit by category, market and segment, yearly and monthly trends, and a statistical test (Spearman correlation) showing that heavy discounts are strongly associated with losses.

Each folder has its own README with the full method, findings, charts and limitations.

## Tools used

Python, pandas, matplotlib, requests, BeautifulSoup, scipy
